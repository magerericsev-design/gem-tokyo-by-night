# GEM — Tokyo by Night

**Offline puzzle game for PC and Android, built iteratively with ChatGPT and Codex.**

GEM is a falling-gem puzzle game with a Tokyo night aesthetic, cascading matches, Arcade modes and FLASH challenges. The PC project is V0.4; an Android test build is available separately.

## Download the Android test build

Open [Releases](https://github.com/magerericsev-design/gem-tokyo-by-night/releases) and download **GEM-Android-V0.4-test1.apk**. Transfer it to your Android device, allow installation from that source when Android asks, then open the APK.

This is a **test build**, not a Google Play release. Its package, ZIP integrity and Android signature were verified before upload; no new physical-device test is claimed by this publication. Existing saves should be preserved. The checksum is provided alongside the APK.
